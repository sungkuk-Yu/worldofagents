## 2. 디자인 원칙 (기획서 요약 → 적용)

1. **채팅버블 탈피 → 기능 중심** — 좌우 말풍선·꼬리·정렬 없음. 모든 결과는 풀스크린 카드/기능 컴포넌트.
2. **세그먼트 = 대화 내 기능 단위** — 정보/데이터/파일/작업/멀티에이전트 5종이 동적 전환.
3. **세그먼트 히스토리 바** — 하단에서 세그먼트들을 연결 레일로 시각화 (탭=복원, 롱프레스=삭제, 스와이프=페이징).
4. **라이트 모드(흰 바탕) + 사각형(네모) 카드** — 반경 4~12px 극소화. 말풍선 형태 폐기.
5. **모던 미니멀 (핀테크 톤)** — 흰 바탕 + 그린 액센트 1색(#00A86B) + 세그먼트 식별색 5종(아이콘·테두리 한정). 삼성 헬스 / 네이버페이 / 토스 톤 참고.
6. **타이포그래피로 화자 구분** — 이름 색상/굵기/크기만으로 구분. 아바타 의존 최소화.
7. **모바일 우선 반응형** — 390×844 기준, 768/1440 변형 제공.
8. **결과 중심 렌더링** — "대화 기록"이 아니라 "그 순간 필요한 결과"가 화면 전체.

## 5. 세그먼트 히스토리 바 설계

- **위치:** 결과 캔버스 하단 고정 레일 (후속 질문 마이크 왼쪽/위). 900px 미만은 하단 고정 유지.
- **구조:** `[아이콘+라벨 노드] ── 연결선 ── [아이콘+라벨 노드(현재)]`
  - 과거 노드: 기본 아이콘 타일, 라벨 3차색
  - 현재 노드: 세그먼트 식별색 타일 + 글로우 + 뉴 닷(신규 세그먼트 표시)
  - 연결선: 완료 구간은 세그먼트색 55%, 미래 구간은 border-strong
- **동작:**
  - 탭 → 해당 컴포넌트 즉시 복원 (`DialogStack.goTo(index)`)
  - 롱프레스 → 삭제 모드 (× 배지 + 확인)
  - 좌/우 스와이프 → 이전/다음 세그먼트 전환
  - 10개 초과 → `+N` 노드로 접고 자동 보관(즐겨찾기 이동)
- **상단 얇은 진행바(F05 상단)**: 화면 10의 "다음 결과로 넘어갈 수 있음" 암시용 보조 표현. 하단 레일과 동일 데이터.

## 7. Figma 임포트 가이드

1. **전체 화면 배치:** `agenttalk-design-system.html`을 브라우저에서 열고, 페이지별 스크린샷 또는 `frames/*.png`를 Figma 캔버스에 드래그 → 이미지 프레임으로 참고 배치.
2. **벡터 재구성 (권장):** `frames/icons/*.svg`를 Figma에 드래그 → 43종 아이콘 벡터 전부 편집 가능. 세그먼트 아이콘 5종(i-info, i-data, i-file, i-task, i-multi)부터 배치.
3. **변수/토큰:** Figma → Variables → Import → `tokens.json` (또는 디자인 토큰 플러그인). 컬러/라디/스페이싱/타이포 변수 자동 생성.
4. **페이지 구성 제안:**
   - Page 1: 핵심 화면 (F01~F10)
   - Page 2: 시스템 (F11 히스토리 바, F12 라이브러리, F13~F14 반응형)
   - Page 3: 아이콘/컴포넌트 정리 (icons/*.svg)
5. **컴포넌트화 우선순위:** JoystickMic → SegIcon(5종) → SegmentHistoryBar → ResultCard → RefBar → Chip/Badge → Stepper.
