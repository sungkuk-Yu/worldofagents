[사업주체명](이하 "회사")은 이용자의 개인정보를 소중하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 방침은 회사가 MyAgentTalk(마이에이전트톡) 서비스(이하 "서비스")를 제공하기 위해 어떤 개인정보를, 왜, 얼마나, 어떻게 처리하는지를 공개하는 문서입니다.

## 제1조 (처리하는 개인정보의 항목)

회사는 서비스 제공을 위해 다음 항목을 처리합니다. **(코드 실측 기준 — 2026-09-26)**

| # | 항목 | 수집 시점 | 처리 목적 |
|---|---|---|---|
| 1 | 이메일 주소, 비밀번호(복호화 불가 형태로 암호화 저장) | 회원가입 | 계정 식별·인증, 서비스 제공(계약 체결·이행) |
| 2 | 닉네임(display_name), 전화번호(선택), 시간대·언어 설정 | 회원가입·프로필 설정 | 서비스 화면 표시, 현지화 |
| 3 | 프로필 정보(MBTI·관심사 등 이용자 특성 — 선택 입력) | 온보딩·프로필 설정 | 페르소나 매칭 등 맞춤형 대화 품질 개선 |
| 4 | 에이전트·페르소나 설정(이용자가 생성한 에이전트의 이름·말투·성격 설정) | 서비스 이용 중 | 이용자별 에이전트 제공 |
| 5 | **대화 내용 전문**(이용자가 입력한 텍스트 메시지 및 에이전트 응답, 스레드·포크 구조 포함) | 채팅 이용 | 대화 서비스 제공, 기억(압축 메모리) 기능, 대화 이력 재표시 |
| 6 | **음성 데이터(음성 입력 시 녹음 데이터)** — 서버 메모리에서 문자로 전사(STT)된 후 **원본 오디오는 서버에 저장하지 않음**(전사 처리 완료 시 파기). 전사된 텍스트는 5번과 동일하게 처리 | 음성 메시지 이용 | 음성→문자 변환을 통한 대화 서비스 제공 |
| 7 | 서비스 이용 기록(접속 이력, 세션·메시지 생성 시각, 피드백), 기기 정보, IP 주소 | 서비스 이용 중 | 부정 이용 방지, 장애 대응, 서비스 안정성 확보 |
| 8 | 결제·구독 정보(결제 수단·구독 상태 — 카드번호 등 민감 결제정보는 PG사/앱마켓이 직접 처리하며 회사는 저장하지 않음) | 유료서비스 구매 | 구독 관리, 환불 처리 |
| 9 | 동의 기록(각 동의 항목·버전·시점) | 회원가입 시 | 동의 사실 입증(법령상 의무) |

- 회사는 **주민등록번호 등 고유식별정보, 사상·신념, 건강, 성생활 등 민감정보를 수집하지 않습니다.**
- 음성 데이터는 전사(轉寫) 목적의 음성인식에만 사용되며, **성문 등 생체인식정보로 활용하지 않습니다.**
- 만 14세 미만 아동의 개인정보는 수집하지 않습니다(회원가입 시 만 14세 이상 확인).

## 제2조 (개인정보의 처리 목적)

1. 회원 식별·인증, 회원가입 의사 확인 및 서비스 제공(계약의 체결·이행)
2. AI 에이전트를 통한 대화 서비스 제공(응답 생성, 기억·압축, 페르소나 적용)
3. 유료서비스(구독) 결제·해지·환불 처리
4. 서비스 개선, 부정 이용 방지, 법령상 의무 이행
5. **(선택 동의 시)** 마케팅 정보 제공 — 동의하지 않아도 서비스 이용에 제한이 없습니다.
6. 회사는 이용자의 **대화 내용을 AI 모델 학습 등 수집 목적 외로 이용하지 않습니다.** 향후 서비스 개선을 위해 대화 데이터를 활용하게 되는 경우, 사전에 별도 동의를 받거나 법령상 허용되는 가명처리(제28조의2) 방식으로만 처리하고 그 사실을 공지합니다.

## 제3조 (처리 근거)

| 처리 | 법적 근거 |
|---|---|
| 계정정보·대화내용 등 서비스 제공에 필수적인 처리 | 개인정보 보호법 제15조 제1항 제4호(계약의 체결 및 이행) |
| 국외 이전(제6조) | 제28조의8 — 가입 시 별도 동의(및 위탁 구성 병행) |
| 마케팅 활용 | 제15조 제1항 제1호 — 별도 (선택) 동의 |
| 동의 기록·접속 로그 보존 | 제15조 제1항 제2호(법령상 의무 준수) |

## 제4조 (개인정보의 보유·이용 기간 및 파기)

1. 회사는 원칙적으로 **이용자의 회원 탈퇴 또는 처리 목적 달성 시 지체 없이** 개인정보를 파기합니다.
2. 구체적인 보유기간:

| 정보 | 보유기간 |
|---|---|
| 계정·프로필·에이전트 설정 | **회원 탈퇴 시 즉시 파기** |
| 대화 전문(messages), 원본 대화 기록(raw_transcripts), 압축 기억, 컨텍스트 기록 | **서비스 이용 중에는 기억 기능 제공을 위해 보유하며, 회원 탈퇴 시 원본 포함 전부 즉시 파기.** [대표님 확정 필요: 탈퇴 전 원본 대화 기록의 별도 보존 기간 상한(예: 최종 활동 후 N개월) — 법률 검토 권고에 따라 무기한 보존은 하지 않음] |
| 음성 원본 오디오 | 전사 완료 즉시(서버에 저장되지 않음) |
| 동의 기록 | 관련 법령에 따른 보존 기간(계약·청약철회 기록: 전자상거래법 제6조 — 5년, 표시·광고: 6개월, 대금결제·재화 공급 기록: 5년) |
| 접속에 관한 통신사실확인자료 | 통신비밀보호법 — 3개월 |

3. **파기 절차·방법**: 전자적 파일 형태는 복원이 불가능한 기술적 방법으로 삭제하며(데이터베이스 행 삭제 및 백업 주기상 만료 시 소멸), 종이 출력물은 분쇄 또는 소각합니다. 회원 탈퇴는 앱 내 설정 화면의 "회원 탈퇴"(DELETE /api/me)로 즉시 처리되며, 탈퇴 시 계정과 연결된 전 테이블의 데이터가 연쇄 삭제(CASCADE)됩니다.
4. 법령상 보존 의무로 분리 보관하는 정보는 해당 목적 외로 이용하지 않습니다.

## 제5조 (개인정보의 제3자 제공 및 위탁)

1. 회사는 원칙적으로 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 단, 법령에 근거한 수사·재판상의 요구 등 예외 사유가 있는 경우 관련 법령에 따라 제공합니다.
2. **위탁**: 회사는 서비스 제공을 위해 다음과 같이 처리 업무를 위탁합니다. (상세 국외이전 사항은 제6조)

| 수탁자 | 위탁 업무 |
|---|---|
| Supabase, Inc. | 데이터베이스 호스팅·보관 |
| OpenAI | 음성 데이터의 문자 전사(STT) 처리 |
| Alibaba Cloud(DashScope) | 대화 응답 생성(AI 언어모델 처리) |

회사는 수탁자와 데이터처리계약(DPA)을 체결하고 처리 목적 제한·안전조치·감독 의무를 계약으로 보장합니다.

## 제6조 (개인정보의 국외 이전 — 중요)

서비스의 기술 구조상 **이용자의 대화 내용과 음성 데이터는 국외로 이전되어 처리됩니다.** 개인정보 보호법 제28조의8에 따라 이전 내용을 공개하며, 회원가입 시 국외이전에 대한 **별도 동의**를 받습니다.

| 이전받는 자(국가) | 이전 항목 | 이전 목적·방법 | 이전 시점 | 보유·이용 기간 |
|---|---|---|---|---|
| **Supabase, Inc.**(데이터 저장 리전: **일본 도쿄, ap-northeast-1** — 실측 확인) | 계정정보, 프로필, 대화 내용 전문, 에이전트 설정, 이용 기록 등 제1조 전 항목 | 서비스 데이터베이스 저장·운영(API 전송, 실시간) | 서비스 이용 시 실시간 | 회원 탈퇴 시 파기(제4조) |
| **OpenAI**(미국) | 음성 입력 데이터(오디오 스트림) | 음성→문자 전사(STT) 처리(Whisper API 전송) | 음성 메시지 전송 시 | OpenAI 정책상 API 데이터는 모델 개선에 사용되지 않으며 전사 처리 목적의 일시적 보유 후 삭제 [OpenAI 약관 기준 — 재확인 필요] |
| **Alibaba Cloud / DashScope**(싱가포르 [추정 — 확인 필요]) | 대화 내용(프롬프트·대화 이력) | AI 응답 생성(언어모델 API 전송) | 메시지 전송 시 실시간 | Alibaba 정책상 API 데이터는 모델 학습에 사용되지 않으며 처리 목적의 일시적 보유 후 삭제 [DashScope 약관 기준 — 재확인 필요] |

> ⚠️ **확인 필요 표시**: DashScope 국제판 엔드포인트의 실제 처리 리전은 미확정(싱가포르 추정)이므로, 정식 게시 전 Alibaba에 확인하여 정확한 국가를 기재해야 합니다(법률 검토 §13-3).

**거부 방법 및 효과**: 이용자는 회원가입 시 국외이전 동의를 거부할 수 있습니다. 그러나 국외이전은 서비스의 핵심 기능(AI 응답 생성·음성 인식·데이터 저장)에 필수적이므로, **거부 시 회원가입 및 서비스 이용이 제한됩니다.**

## 제7조 (이용자의 권리·의무 및 행사 방법)

1. 이용자는 언제든지 다음 권리를 행사할 수 있습니다:
   - **열람**: 자신의 개인정보 및 대화 이력 확인(앱 내 화면 또는 요청)
   - **정정·삭제**: 프로필 정보 수정, 개별 대화·세션 삭제, 계정 정보 정정 요청
   - **처리정지·동의 철회**: 마케팅 동의 철회(설정 화면), 개인정보 처리 정지 요구
   - **회원 탈퇴(파기)**: 설정 화면의 회원 탈퇴 — 탈퇴 시 전 데이터 즉시 파기(제4조)
   - 만 14세 미만 아동에 관한 권리는 법정대리인이 행사합니다(본 서비스는 만 14세 이상만 이용 가능)
2. 행사 방법: 앱 내 설정 화면에서 직접 처리하거나, 개인정보 보호책임자에게 이메일 등으로 요청하면 **접수 후 10일 이내**에 조치하고 결과를 통보합니다.
3. 회사는 권리 행사 시 본인(또는 정당한 대리인) 여부를 확인합니다.
4. 처리정지 요구에도 법령상 보존 의무 등 정당한 사유가 있는 경우 처리가 계속될 수 있으며, 그 사유를 통지합니다.
5. 이용자는 자신의 개인정보를 최신 상태로 유지할 의무가 있으며, 타인의 개인정보를 침해·도용해서는 안 됩니다.

## 제8조 (개인정보의 안전성 확보 조치)

회사는 개인정보 보호법 제29조에 따라 다음 조치를 시행합니다:

1. 관리적: 내부관리계획 수립·시행, 접근 권한 최소화(서비스 역할 키 분리), 직원 교육
2. 기술적: 비밀번호 암호화 저장, 전송 구간 암호화(TLS), 데이터베이스 행 수준 보안 정책(RLS — 이용자 본인의 데이터만 접근 가능), 접근 로그 기록
3. 물리적: 클라우드 데이터센터(Supabase) 접근 통제 — 수탁자 책임 영역
4. **유출 사고 대응**: 개인정보 유출을 인지한 경우 지체 없이(72시간 이내) 이용자에게 알리고 개인정보보호위원회에 신고합니다(제34조).

## 제9조 (개인정보 보호책임자 및 고충 처리)

| 구분 | 내용 |
|---|---|
| 개인정보 보호책임자(CPO) | [대표님 확정 필요 — 성명·직책] |
| 연락처 | [대표님 확정 필요 — 이메일·전화] |
